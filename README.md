        <h2 class="tex1">A História da Programação</h2>

        <section>
        <p>
            A programação é a base do mundo digital em que vivemos. Sempre que usamos um aplicativo, acessamos um site, realizamos uma transferência bancária ou até interagimos em uma rede social, existe um conjunto de códigos trabalhando nos bastidores. Esses códigos são criados por meio da programação, que evoluiu ao longo dos anos até se tornar essencial para a sociedade moderna.
A origem da programação remonta ao século XIX, quando o matemático Charles Babbage idealizou a Máquina Analítica, considerada um dos primeiros projetos de computador. A matemática Ada Lovelace desenvolveu um algoritmo para essa máquina, tornando-se reconhecida como a primeira programadora da história.
Já na década de 1940, surgiram os primeiros computadores eletrônicos, como o ENIAC. Nessa época, programar era uma tarefa complexa, realizada diretamente em linguagem de máquina, utilizando apenas números binários (0 e 1).
A partir dos anos 1950, foram criadas linguagens de programação que facilitaram a escrita de códigos, como FORTRAN e COBOL. Em 1972, a linguagem C trouxe ainda mais avanço e influenciou diversas linguagens modernas.
Com o tempo, surgiram novas abordagens, como a Programação Orientada a Objetos, utilizada em linguagens como Java e C++. Essas linguagens permitiram o desenvolvimento de sistemas maiores e mais organizados.
Hoje, linguagens como JavaScript e Python são amplamente utilizadas no desenvolvimento web, aplicativos, jogos e inteligência artificial.
A história da programação mostra uma trajetória de constante evolução, acompanhando o avanço da tecnologia e transformando a maneira como vivemos, trabalhamos e nos comunicamos.
   </p><br>
</section>
